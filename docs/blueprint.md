# **App Name**: Brainrot Creator

## Core Features:

- Prompt Input: Allows the user to enter a prompt for content generation.
- Story Generation: Generates a short story script based on the user's prompt, optimized for cinematic visuals.
- Visual Generation: Generates a cinematic visual (image) based on the generated story script.
- Voiceover Generation: Generates a voiceover narration of the story script, using a dramatic voice.
- Result Display: Displays the generated story script, visual, and voiceover to the user.
- Audio Playback: Plays the generated voiceover audio synchronized with the displayed visual.
- Error Handling: Displays error messages to the user in case of generation failures.
- Loading Indicator: Shows a loading animation while the story, image, and voiceover are being generated.
- Firebase Authentication: Authenticates the user anonymously or with a custom token for tracking and debugging.

## Style Guidelines:

- Background color: Light gray (#f4f7f9).
- Card background color: Semi-transparent white (rgba(255, 255, 255, 0.8)) with backdrop blur.
- Audio player background color: Blue (#3b82f6).
- Body font: 'Inter', sans-serif.
- Header font: 'Inter', sans-serif, bold.
- Uses loading spinner and error icons for feedback.
- Centered layout with a maximum width for readability.
- Subtle transitions on button hover effects.
